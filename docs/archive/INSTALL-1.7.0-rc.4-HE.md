# Grab 1.7.0-rc.4 — התקנה, הפעלת התוסף ובדיקות

זו גרסת בדיקה מאוחדת: תיקוני התור, השחזור, ההשהיה, הסשנים והעדכון יחד עם תוסף Chrome/Edge/Brave ובחירת דפדפן. מתקינים את המתקין של הבראנץ׳; הגרסה הישנה בעמוד Releases אינה כוללת את השינויים.

בגרסה זו הוסרה הבחירה הידנית ליד תיבת הקישור. הדבקה מפעילה הורדה רגילה; שליחה מהתוסף מפעילה הורדה אוטומטית בסשן של הדפדפן ששלח. תוקן גם רישום החיבור של Brave ב־Windows והזיהוי שלו בנפרד מ־Chrome. אם התוסף כבר מותקן, לאחר השדרוג לחץ תיקון ב־Grab וטען מחדש את התוסף בדפדפן; ודא שהגרסה שלו היא 1.1.3.

## 1. הורדה והתקנה

1. סגור את Grab. שמור עותק של ההגדרות וההיסטוריה. ב־PowerShell:
   ```powershell
   $grabBackup = Join-Path ([Environment]::GetFolderPath('Desktop')) ('Grab-backup-' + (Get-Date -Format 'yyyyMMdd-HHmmss'))
   Copy-Item "$env:APPDATA\Grab" $grabBackup -Recurse
   ```
   אם Grab לא הותקן בעבר, אין צורך בגיבוי.
2. פתח את ריצת **Browser integration** המוצלחת האחרונה של הבראנץ׳ `feature/browser-extension-integration`:
   https://github.com/OrMeirDev/Grab/actions/workflows/browser-integration.yml
3. תחת **Artifacts**, הורד `Grab-1.7.0-rc.4-Windows`. חלץ את ה־ZIP. הוא מכיל את המתקין, הקובץ הזה ו־`SHA256SUMS.txt`.
4. בדיקת תקינות הקובץ, מאותה תיקייה:
   ```powershell
   (Get-FileHash .\Grab-Setup-1.7.0-rc.4.exe -Algorithm SHA256).Hash
   Get-Content .\SHA256SUMS.txt
   ```
   שני ערכי ה־SHA256 צריכים להיות זהים, בלי חשיבות לאותיות גדולות/קטנות.
5. הפעל `Grab-Setup-1.7.0-rc.4.exe` והתקן מעל Grab הקיים באותה תיקייה. המתקין אינו חתום, כמו הגרסה הקודמת; אם SmartScreen מציג אזהרה, לאחר בדיקת הקובץ בחר **מידע נוסף → הפעל בכל זאת**.
6. פתח Grab וודא שמופיע `1.7.0-rc.4`. ההגדרות וההיסטוריה הקיימות צריכות להישאר. תור שהגרסה החדשה שומרת משוחזר אחרי הפעלה מחדש; הורדות שהופסקו חוזרות מושהות.

לא נדרשים Node.js, Python, סביבת פיתוח או הורדת מנועים בנפרד. גרסת הבדיקה אינה מפורסמת בערוץ העדכונים הרגיל; מתקינים אותה ידנית.

## 2. שני מסלולי ההורדה — זיהוי אוטומטי

- **קישור רגיל:** הדבק כתובת ב־Grab וזהה/הורד כרגיל. YouTube, Vimeo וקישורים ציבוריים מגיעים ישירות למנוע ההורדה בלי להפעיל דפדפן או תוסף. אין תפריט לבחירת מסלול; דפדפן ברירת המחדל בהגדרות אינו משפיע על קישורים רגילים.
- **תוסף ודפדפן:** פתח את העמוד בדפדפן שבו אתה מחובר, ואז בתוסף לחץ **שלח ל־Grab**. הזיהוי והתור ממשיכים אוטומטית עם הדפדפן והפרופיל ששלחו. אין צורך לבחור מסלול או דפדפן ב־Grab. כך שולחים Schooler ועמודים שמורכב למצוא את המקור שלהם.
- **מאקו** ממשיך דרך Edge לפי הכלל הייעודי שלו, גם בהדבקה רגילה.

אם קישור נשאר בתור עם שגיאה מגרסה ישנה, הסר את השורה והדבק מחדש, או שלח מחדש מהתוסף בהתאם לצורך.

### תיקון החיבור של Brave לאחר השדרוג

1. ב־Grab: **הגדרות → דפדפן והרחבה → Brave → תיקון**.
2. ב־Brave: פתח `brave://extensions`, מצא את Grab ולחץ **Reload / טעינה מחדש**. ודא שגרסת התוסף `1.1.3`.
3. פתח את התוסף, לחץ חיבור מחדש אם צריך, וחזור ל־Grab ל־**בדוק חיבור** ליד Brave. צפוי **מחובר** תחת Brave.
4. אם גם Chrome מחובר, הוא צריך להופיע בנפרד. שליחה מ־Brave משתמשת ב־Brave גם אם ברירת המחדל השמורה היא Chrome.

### הפעלה חד־פעמית בכרום שלך — למסלול התוסף בלבד

1. פתח את **Chrome בפרופיל הרגיל שלך**, שבו אתה כבר מחובר לאתרים.
2. ב־Grab: **הגדרות → דפדפן והרחבה → Google Chrome → התקנה**.
3. בכרום, הדבק בשורת הכתובת: `chrome://extensions`.
4. הפעל **Developer mode / מצב מפתח**.
5. לחץ **Load unpacked / טען תוסף לא ארוז** ובחר:
   ```text
   %LOCALAPPDATA%\Grab\browser-integration\extension
   ```
   אפשר להעתיק את הנתיב המלא או לפתוח את התיקייה דרך Grab. בחר את התיקייה עצמה, לא קובץ מתוכה.
6. חזור ל־Grab ולחץ **בדוק חיבור** ליד Chrome. צפוי: **מחובר**, עם שם הפרופיל.
7. הגדר את **Chrome כדפדפן ברירת המחדל להורדות בעזרת התוסף**. אפשר להצמיד את התוסף לסרגל הכלים בכרום.

אין צורך להתחבר לאתר דרך Grab או להפעיל Remote debugging לשימוש בתוסף. אם חיברת כמה פרופילי Chrome, בחר בהגדרות את הפרופיל הרצוי; Grab לא אמור לנחש או להשתמש בפרופיל אחר.

**אם כבר התקנת גרסה קודמת של תוסף Grab:** לחץ **תיקון** ב־Grab, ואז בדף ההרחבות בכרום לחץ על סמל **Reload / טעינה מחדש** של תוסף Grab. גרסת התוסף צריכה להיות `1.1.3`. תיקון הקבצים לבדו אינו טוען מחדש תוסף שכבר פועל.

## 3. mako דרך Edge בלבד

1. הפעל את Edge בפרופיל שבו הסרטון מתנגן אצלך.
2. חזור על שלבי ההתקנה לתוסף, הפעם ליד Edge ב־Grab ובכתובת `edge://extensions`.
3. בדוק חיבור ל־Edge.
4. בהגדרות Grab, ודא שקיים הכלל **`mako.co.il → Microsoft Edge`**.

הדבקת מאקו בוחרת Edge אוטומטית לפי הכלל, שחל גם על תתי־דומיינים אמיתיים של mako. אין בחירה ליד תיבת ההדבקה. Chrome יכול להישאר ברירת המחדל בהגדרות; קישורים ציבוריים רגילים אינם משתמשים בו, ושליחה מתוסף משתמשת בדפדפן ששלח.

## 4. בדיקות קצרות על המחשב שלך

סמן כל סעיף אחרי שהקובץ הסופי מתנגן, עם תמונה וקול כשמדובר בווידאו. השתמש בתוכן ובחשבונות שלך שמותר לך להוריד מהם.

- [ ] **סרטון ציבורי:** סגור את הדפדפן והדבק כתובת → זהה → הורד MP4. בדוק גם MP3. הקבצים מופיעים בהיסטוריה ובספרייה.
- [ ] **שני סרטוני YouTube:** במסלול הרגיל ובלי חיבור לתוסף, זהה שני קישורים → הורד הכול. השני מתחיל לבד אחרי ההפסקה; כל סרטון יורד פעם אחת.
- [ ] **אתר עם התחברות בכרום:** ודא שהעמוד מתנגן בפרופיל שלך ושלח אותו מהתוסף. צפוי: זיהוי והורדה אוטומטית באותו סשן, בלי בחירת מסלול ב־Grab.
- [ ] **Brave:** לאחר תיקון וטעינה מחדש ודא שבדיקת החיבור עובדת וששליחה מהתוסף מורידה ב־Brave גם כש־Chrome מחובר וברירת המחדל השמורה שונה.
- [ ] **שלח ל־Grab:** השאר Grab פתוח, פתח עמוד בכרום → לחץ על התוסף → שלח ל־Grab. צפוי: שורה אחת בתור והתחלת הורדה אוטומטית לאחר הזיהוי; אישור הקבלה אינו מוצג כהורדה שהושלמה. „הושלם” מופיע אחרי שהקובץ נוצר ונבדק.
- [ ] **בחירת סרטון:** אם נמצאו כמה סרטונים, בחר בשורה את המקור הרצוי. אותה שורה ממשיכה בתור.
- [ ] **כרטיסייה קיימת:** הפעל סרטון, עצור וגלול בעמוד. שלח את העמוד מהתוסף. הכרטיסייה שלך לא אמורה להיטען מחדש, להתנגן מחדש או להיסגר.
- [ ] **צריך Play:** אם Grab מבקש הפעלה, לחץ בשורה „הצג את הלשונית”, נגן את הסרטון והמשך בתוך חלון הזמן.
- [ ] **mako:** הדבק עמוד mako חדש וודא שמוצג Edge. הורד ובדוק את הקובץ בפועל.
- [ ] **ביטול זיהוי:** לחץ X בזמן זיהוי. השורה מסיימת כ־„בוטל”, אינה חוזרת לחפש לבד, וכרטיסיות שלך נשארות פתוחות.
- [ ] **השהיה וחידוש:** השהה הורדה גדולה והמשך אותה. בסיום יש קובץ סופי אחד, בלי הורדה מקבילה כפולה.
- [ ] **הפעלה מחדש:** סגור Grab בזמן הורדה ופתח שוב. השורה חוזרת מושהית. „המשך” רוכש שוב את הסשן וממשיך; שום הורדה אינה מתחילה לבד.
- [ ] **ניתוק במסלול התוסף:** נתק/סגור את הפרופיל אחרי הזיהוי ונסה להוריד. Grab צריך לרכוש את אותו סשן מחדש, או להציג שגיאת חיבור/פרופיל; לא לעבור לדפדפן אחר. פתח מחדש את הפרופיל ונסה שוב.

הבדיקות האוטומטיות משתמשות בפרופילים זמניים ובאתרי בדיקה. הן אינן מוכיחות שהחשבון האישי או הסרטון המסוים שלך נגישים. תוכן מוגן DRM אינו נתמך.

## 5. אם משהו נכשל

1. רשום את מספר הסעיף, השעה, הדפדפן והגרסה, והודעת השגיאה המדויקת.
2. ודא שהעמוד עצמו מתנגן בפרופיל שנבחר. בשגיאת חיבור: לחץ תיקון, טען מחדש את התוסף ובדוק חיבור.
3. שמור צילום מסך ואת `%APPDATA%\Grab\logs\diagnostics.log`. הלוג מסנן עוגיות וחתימות, אבל נתיב של עמוד עשוי לחשוף שם קורס; עבור עליו לפני שיתוף.
4. אם צריך לחזור לגרסה הקודמת: הסר את גרסת הבדיקה בלי למחוק נתוני משתמש, התקן את 1.6.7 מעמוד Releases והחזר את הגיבוי כשהאפליקציה סגורה, אם נדרש. 1.6.7 אינה תומכת בתוסף החדש.

## 6. הסרת החיבור

הסר את תוסף Grab מ־`chrome://extensions`, מ־`brave://extensions` וב־Edge אם הותקן גם שם. אפשר להסיר את רכיב החיבור מתוך הגדרות Grab כשאין פעולה פעילה. הסרה מלאה של האפליקציה מנקה את מפתחות Native Messaging של Grab ואת תיקיית החיבור שלה; שדרוג שומר את תיקיית התוסף במקומה. קבצי ההורדות שלך אינם נמחקים.
