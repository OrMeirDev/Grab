# Grab 1.7.1

עדכון פרטיות, חיבור דפדפנים ואמינות הזיהוי וההמשך.

- הוקשח היקף העוגיות שנשלחות למנוע: host-only, דומיין, נתיב ו־Secure, גם בהפניות ובמקטעי HLS. תוסף הפרטיות של המנוע הוא חובה; אימות אינו עובר למקור אחר.
- צומצמו נתוני הבקשות והלוגים. לוגים ישנים עוברים ניקוי אוטומטי לפי רשימת השדות המותרת, ונתוני סשן נשארים פרטיים.
- עותק המארח לחיבור הדפדפן מאומת לפי תוכן הקבצים, גם כשמספר הגרסה וגודל הקובץ לא השתנו.
- הרחבה **1.1.6**: זמני סריקת עמוד וטעינה מוגבלים, סריקה ממתינה אינה מוכפלת, ותקלת timeout מדווחת עם שלב הזיהוי. לשוניות אישיות אינן נטענות מחדש או נסגרות.
- חידוש עבודה שמורה מפעיל את הדפדפן אם הוא סגור וממתין לפרופיל הזכור בלבד. מאקו ממשיך דרך Edge.
- הדבקת קישורים ציבוריים נשארת ישירה, ללא תלות בתוסף. שליחה מההרחבה שומרת את הדפדפן והפרופיל השולח.

**שדרוג:** התקן את `Grab-Setup-1.7.1.exe` מעל ההתקנה הקיימת. ההגדרות, ההיסטוריה והתור נשמרים; עבודה שנקטעה חוזרת מושהית. ב־Grab לחץ **תיקון**, ואז טען מחדש את ההרחבה בדפדפנים שבהם היא כבר מותקנת כדי להפעיל את **1.1.6**.

הפרסום משתמש במתקין שנבדק ב־CI מאותו commit, עם קובצי עדכון, manifest וגיבובים מצורפים. גרסאות המנועים לא שונו. המתקין אינו חתום, כמו בגרסה הקודמת.

**היקף הבדיקות:** בדיקות CI משתמשות בפרופילים זמניים ובאתרי בדיקה. בדיקות נוספות בפרופילים האישיים, חידוש מאקו לאחר התקנת התיקון כשה־Edge סגור, משתמש רגיל אמיתי במחשב האישי והעדכון המקומי מתוך האפליקציה עדיין נמשכות. אין בכך טענה שנבדקה כל פלטפורמה או כל חשבון.

[הוראות התקנה](https://github.com/OrMeirDev/Grab/blob/main/docs/INSTALL-WINDOWS-HE.md).

## English

Privacy and browser-discovery reliability update. The mandatory engine plugin enforces exact
cookie scope across redirects and HLS fragments; authentication stays within its origin. Existing
diagnostic logs are migrated through the current allowlist. Private browser-host runtimes are
verified by file contents rather than version and size alone.

Extension **1.1.6** bounds discovery waits, reuses pending scans and reports an allowlisted failure
stage. Resuming a job now starts a closed browser while still requiring its remembered profile.
Public pastes retain the direct route; extension Sends retain their sending browser/profile, and
Mako retains its Edge rule. Bundled engine versions are unchanged.

Install **Grab-Setup-1.7.1.exe** over the current installation, then Repair in Grab and Reload the
extension in the relevant browsers. Settings, history and paused jobs are retained. The release
contains the exact CI-tested installer, updater metadata, source manifest and checksums. The
installer remains unsigned.

Automated checks use disposable profiles and controlled fixtures. Further personal-profile Sends,
installed Mako restart/resume with the closed-browser fix, genuine local standard-user acceptance
and the local in-app update check remain ongoing. This release does not claim compatibility with
every live platform or account.
