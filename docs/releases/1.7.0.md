# Grab 1.7.0

גרסה מלאה הכוללת את העבודה המאוחדת על ההורדות, התור ותוסף הדפדפן.

- הדבקת קישורים רגילים, כולל YouTube, פועלת בלי תלות בתוסף או בדפדפן.
- שליחה מתוסף Chrome, Edge או Brave מתחילה זיהוי והורדה אוטומטית בסשן של הדפדפן ששלח. הוסרה בחירת המסלול ליד תיבת הקישור.
- תוקן החיבור של Brave והזיהוי שלו בנפרד מ־Chrome. מאקו ממשיך להשתמש ב־Edge.
- תור עמיד להפעלה מחדש, השהיה וחידוש, טיפול במגבלות אתר וניקוי תהליכים וקובצי סשן.
- הורדה נחשבת שהושלמה רק לאחר בדיקת קובץ הפלט. סשנים נשמרים פרטיים ונרכשים מחדש לפני חידוש הורדה שדורשת חשבון.
- פרסום ממקור שעבר בדיקות Linux/Windows, תוסף אמיתי, Brave, אריזה ושדרוג. קובצי העדכון וה־SHA256 מצורפים לגרסה.

**שדרוג:** התקן את `Grab-Setup-1.7.0.exe` מעל ההתקנה הקיימת. ההגדרות וההיסטוריה נשמרות. גרסת התוסף היא **1.1.3**; אם נדרש עדכון, לחץ תיקון ב־Grab וטען מחדש את התוסף בדפדפן.

[הוראות התקנה](https://github.com/OrMeirDev/Grab/blob/main/docs/INSTALL-WINDOWS-HE.md).

## English

Stable release combining the download lifecycle fixes and browser extension. Public pasted links
remain independent of browser setup. Extension Send downloads automatically in its sending
session; Brave connects and is identified separately from Chrome, and Mako retains its Edge rule.
The release includes persistent paused restore, session-safe retries, verified output, bounded
process shutdown, and the installer/update metadata from the tested Windows build.

Upgrade over the existing installation. Extension version: **1.1.3**. Repair and Reload an older
extension when needed. Bundled engine versions remain pinned in `native-tools.lock.json`.
