# Grab 1.9.0

**זיהוי אוטומטי של וידאו ו־PDF**, בלי לבחור סוג הורדה מראש:

- הדבק קישור ולחץ **זהה קבצים**, או שלח מהתוסף.
- Grab מזהה את סוג הקובץ לבד. אם נמצאים כמה קבצים, כולל וידאו ו־PDF יחד, בחר את הרצוי.
- מסמכי PDF נשמרים כמסמכים מקוריים; הגדרות MP4/MP3 והאיכות ממשיכות לחול על הווידאו.
- שליחה מהתוסף שומרת על הדפדפן והפרופיל שבהם אתה מחובר.
- קישורי וידאו רגילים ממשיכים במסלול הישיר הקיים, בלי תלות בתוסף.

עדכן מתוך Grab או התקן את **Grab-Setup-1.9.0.exe** מעל ההתקנה הקיימת.
לאחר העדכון: **הגדרות Grab → תיקון**, ואז **טעינה מחדש** של התוסף בדפדפן.
גרסת התוסף הנדרשת: **1.3.0**. ההגדרות וההיסטוריה נשמרות.

העיצוב וגודל הטקסט נשמרו. כלי ההורדה המצורפים לא שונו. המתקין אינו חתום, כמו בגרסאות
הקודמות. זיהוי אוטומטי אינו מבטל את מגבלות האתר: מסמך HTTP(S) מקורי צריך להיות זמין;
כתובת חתומה שפגה או משאב אטום שלא זוהה עשויים לדרוש פתיחה מחדש באתר. אין יצירת PDF מעמוד.
הבדיקות משתמשות באתרי בדיקה ופרופילים זמניים ואינן אימות של כל חשבון אישי.

## English

Automatically detect video and original PDFs in pasted links and browser Sends. Both mode
selectors are removed. Choose a file only when multiple candidates are exposed. Each job retains
its concrete type, PDF files keep their original bytes, and video format/quality settings continue
to apply only to video jobs. Sending browser/profile session scope and ordinary direct video
routing are preserved.

Update Grab or install Grab-Setup-1.9.0.exe over the existing installation, Repair browser
integration, then Reload extension 1.3.0. Settings/history are retained. Bundled tools, styling,
font sizes and installer signing are unchanged. Original HTTP(S) file availability and signed-URL
expiry limitations still apply. Controlled automated profiles do not verify every personal account.
