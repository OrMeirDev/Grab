# Grab 1.8.0

הורדת קובצי **PDF מקוריים** לצד הורדת הווידאו והאודיו הקיימת.

- מצב **PDF** חדש באפליקציה ובתוסף: קישור ישיר למסמך או איתור מסמכים בעמוד.
- זיהוי קישורים ומסמכים מוטמעים, כולל תגובות PDF שהדפדפן ראה. כשיש כמה מסמכים, בוחרים את הרצוי.
- שליחה מהתוסף שומרת את הדפדפן והפרופיל השולח גם למסמכים שדורשים התחברות.
- המסמך המקורי נשמר בספרייה ובהיסטוריה וניתן להורדה חוזרת כ־PDF.
- הורדות PDF נבדקות מול חתימת PDF, סמן סוף הקובץ ואורך התגובה כשנמסר; קובץ קיים אינו נדרס.
- הורדת סרטונים מקישור רגיל נשארת ישירה, ומאקו שומר על מסלול Edge הקיים.

**שדרוג:** עדכן מתוך Grab או התקן את `Grab-Setup-1.8.0.exe` מעל ההתקנה הקיימת.
לאחר מכן לחץ **תיקון** בהגדרות Grab וטען מחדש את ההרחבה בדפדפנים הרלוונטיים להפעלת **1.2.0**.

**מגבלות:** נתמכים מסמכים מקוריים דרך HTTP/HTTPS; אין הדפסת עמוד ל־PDF. מסמכי blob/data
והורדות שמחייבות לחיצה או POST ואינן חושפות כתובת מסמך אינם נתמכים בגרסה זו. המשך PDF
מושהה מתחיל את הקובץ מחדש. הגודל המרבי הוא 1 GiB. המתקין אינו חתום, כמו בגרסה הקודמת.
גרסאות כלי ההורדה המצורפים לא שונו. הבדיקות האוטומטיות משתמשות באתרים ובפרופילים זמניים;
אין טענה לתאימות לכל אתר או לכל חשבון אישי.

## English

Download original PDFs alongside the existing video/audio flow. Select PDF in Grab or its browser
extension, paste a document/page URL, and choose a document when several are found. Browser Sends
retain their sending profile and scoped session. PDF files appear in the existing library/history
and retain their type when downloaded again. Original public video pastes remain independent of
the extension, and the established Mako/Edge route is preserved.

Update through Grab or install **Grab-Setup-1.8.0.exe** over the existing installation. Repair the
browser integration in Grab settings, then Reload extension **1.2.0** in the relevant browsers.
Only original HTTP(S) documents are supported; HTML-to-PDF, browser-only blob/data files and
click/POST-only downloads without a document address are outside this release. Paused PDF downloads
restart the document. Maximum size is 1 GiB. Signature/EOF/length checks detect common bad responses;
they are not a full PDF parser. Bundled engines are unchanged and the installer remains unsigned.
Automated verification uses controlled fixtures and disposable profiles, not every live account.
