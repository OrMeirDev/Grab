# Grab 1.7.1 — התקנה ושימוש ב־Windows

## התקנה או שדרוג

1. הורד את [Grab-Setup-1.7.1.exe](https://github.com/OrMeirDev/Grab/releases/download/v1.7.1/Grab-Setup-1.7.1.exe) מתוך [עמוד הגרסה](https://github.com/OrMeirDev/Grab/releases/tag/v1.7.1).
2. סגור את Grab והתקן מעל ההתקנה הקיימת, באותה תיקייה. אין צורך להסיר את הגרסה הישנה. ההגדרות וההיסטוריה נשמרות; הורדות שהופסקו חוזרות מושהות.
3. פתח Grab וודא שמופיעה גרסה **1.7.1**. המתקין אינו חתום, כמו הגרסאות הקודמות. אם Windows מציג SmartScreen, בדוק את מקור הקובץ ובחר מידע נוסף → הפעל בכל זאת.

אין צורך להתקין Node.js, Python או מנועי הורדה בנפרד. גרסאות מלאות מופיעות גם בערוץ העדכונים של Grab. אם אתה מגיע מגרסת RC ואינך רואה עדכון, השתמש במתקין שבקישור.

לבדיקת הקובץ אפשר להוריד מאותו עמוד את `SHA256SUMS.txt` ולהשוות ב־PowerShell:

```powershell
(Get-FileHash .\Grab-Setup-1.7.1.exe -Algorithm SHA256).Hash
Get-Content .\SHA256SUMS.txt
```

## הורדה רגילה

הדבק קישור ב־Grab → זהה → הורד. קישורים ציבוריים כמו YouTube אינם דורשים דפדפן או תוסף. אין תפריט לבחירת מסלול. מאקו ממשיך דרך Edge לפי הכלל הייעודי.

## הורדה מהתוסף

פתח את העמוד בפרופיל שבו אתה מחובר ולחץ בתוסף **שלח ל־Grab**. הזיהוי וההורדה ממשיכים אוטומטית עם הדפדפן והפרופיל ששלחו, גם אם ברירת המחדל השמורה שונה. אין צורך לבחור מסלול ב־Grab.

להפעלה ראשונה:

1. ב־Grab: הגדרות → דפדפן והרחבה → התקנה ליד Chrome, Edge או Brave.
2. באותו דפדפן פתח `chrome://extensions`, `edge://extensions` או `brave://extensions`.
3. הפעל Developer mode → Load unpacked ובחר את התיקייה שמוצגת ב־Grab:
   `%LOCALAPPDATA%\Grab\browser-integration\extension`.
4. חזור ל־Grab ולחץ בדוק חיבור. צפוי **מחובר** ליד הדפדפן הנכון.

אם התוסף כבר מותקן, הגרסה הנדרשת היא **1.1.6**. אם זו כבר הגרסה שפועלת והחיבור תקין, אפשר להמשיך להשתמש בו. אחרי תיקון/עדכון קבצי התוסף: ב־Grab לחץ **תיקון**, ובדף ההרחבות בדפדפן לחץ **טעינה מחדש** ליד Grab ואז בדוק חיבור. אין צורך לשנות את פרופיל הדפדפן.

## מאקו ו־Edge

התקן את התוסף גם בפרופיל Edge שבו הסרטון מתנגן, ובדוק שבהגדרות Grab קיים הכלל `mako.co.il → Microsoft Edge`. הדבקת עמוד מאקו בוחרת Edge אוטומטית. אין שינוי במסלול ההורדה הרגילה של YouTube ואתרים ציבוריים אחרים.

## אם נתקעת

בדוק שהעמוד עצמו מתנגן בפרופיל הנכון. בשגיאת חיבור לחץ תיקון, טען מחדש את התוסף ובדוק חיבור. אפשר להסיר שורת שגיאה שנשארה מגרסה ישנה ולשלוח מחדש. אין להחליף את תיקיית התוסף הקבועה בתיקייה זמנית. תוכן DRM אינו נתמך.
